## 导出仍无反应 —— 彻底排查与根因修复
- 排查：按钮 id `popup-export-data` 与 popup.js 651 行绑定均正确，事件能触发；问题在 background 下载实现。
- 根因：MV3 service worker 中用 `URL.createObjectURL(blob)` 生成 `blob:` URL 交给 `chrome.downloads.download`，blob 存于 worker 的 Blob URL store，worker 可能在异步下载开始前被回收 → blob URL 失效 → 下载静默失败（popup 收到 lastError 但无可见反馈）。
- 修复：`js/background.js` 的 `exportAllData` 改用**自包含 data URL**（`data:application/json;charset=utf-8,` + encodeURIComponent(json)）传给 `chrome.downloads.download`，不再依赖 blob 生命周期。注意 data URL 有约 2MB 上限，超大备份可能失败（当前场景可接受）。
- 按钮视觉最终定稿（与"完成"按钮一致）：白底 `#ffffff` + 深字 `#3a3e5c` + 淡紫边 `rgba(124,108,255,.18)` + 大圆角 `999px`；hover 浅紫底 `#f1edff` + 紫字 `#6d5ef0`；去掉浅色主题单独覆盖（白底深字在浅色下已对）。

## 导出改为仅设置 + 彻底修复"无反应"
- 用户诉求：只导出/导入设置记录（API 设置等），不要生词本/历史；且点击导出仍无反应。
- 根因（关键）：`exportAllData` 原由 background service worker 调用 `chrome.downloads.download`。MV3 service worker 是短生命周期，异步下载回调前 worker 可能被回收，下载静默失败，popup 收到 lastError 但无可见反馈。消息通道 `return true` 本身没问题。
- 修复：导出逻辑移回 **popup 端**直接调用 `chrome.downloads.download`（popup 是常驻页面，不会被回收），用自包含 data URL（`data:application/json;charset=utf-8,` + encodeURIComponent）避免 blob 生命周期问题。
- 范围缩减：导出/导入内容从 `settings+vocabulary+history` 改为仅 `settings`。文件名 `lingoflow-backup-*.json` → `lingoflow-settings-YYYY-MM-DD.json`。
- 导入：`onImportFileSelected` 校验改为只接受含 `settings` 字段的文件，发送 `{settings: parsed.settings}` 给 background，仅恢复设置（background 的 importAllData 按字段选择性 set，自然只写 settings）。
- 涉及：js/popup.js（exportAllData 重写、onImportFileSelected 校验+payload）、js/background.js（exportAllData 同步为仅 settings）、manifest.json 的 downloads 权限已存在。
- 验证：`node --check` 通过，无 lint 错误。

## 导出仍报错 `chrome.downloads` undefined —— 加 fallback
- 用户再次报错：popup 端 `chrome.downloads.download` 抛出 `TypeError: Cannot read properties of undefined (reading 'download')`，且导出无反应。
- 根因：扩展未刷新时，新声明的 `downloads` 权限未生效，API 未注入到 popup 上下文。`chrome.downloads` 在权限未加载前为 `undefined`。
- 修复：`js/popup.js` 的 `exportAllData` 先判断 `chrome.downloads && chrome.downloads.download` 是否存在：
  - 存在则调用 `chrome.downloads.download`（权限生效后走此路径，文件名正确）；
  - 不存在则 fallback 到 `<a download>` + data URL，不依赖任何权限即可触发下载。
- 新增 `fallbackDownload(url, filename)` 函数：创建隐藏 `<a>`，设置 `href=data:...` 和 `download=filename`，点击后 1 秒移除。
- 验证：`node --check` 通过，无 lint 错误。
