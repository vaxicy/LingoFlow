## NVIDIA NIM 教程流程修正（commit 57c7cb8）

- 根因：原教程步骤 2/3 顺序错（先搜 riva-translate 再获取 API Key），且步骤 3 没说明 API Key 来自模型详情页代码区右上角的「Generate API Key」按钮；步骤 4 漏了**模型名称**的获取（用户截图明确展示代码里 `model="z-ai/glm-5.2"` 即模型名）。
- 正确流程：登录 → Models 页筛选 Free Endpoint 选模型 → 进入详情页点「Generate API Key」生成 key → 同一代码区拿到 Base URL + model 名 → 自定义接口填 Host / Key / Model。
- 教训：**写教程时务必按截图/官方文档核对每一步的实际位置和顺序**，不能凭"大概是这样"写。
- 描述从"含翻译模型 riva-translate"改为"可接入多种开源模型"（riva-translate 不一定还在 Free Endpoint 列表）。
