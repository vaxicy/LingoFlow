## 打赏页按钮点不了 + CSP 报错根治（commit f386a7b）

- 根因：Chrome MV3 默认 CSP `script-src 'self'` **拒绝 inline `<script>` 无 src 块**。support.html 第 85-147 行整块 IIFE 被拦 → 整个 JS 失效 → click 绑定没挂上 → 按钮点不了；且报 `Executing inline script violates the following CSP directive`。
- 修复：
  1. 新建 `pages/support.js`（外部脚本，CSP 通过），把原 inline script 全部抽过去。
  2. support.html 改为 `<script src="support.js"></script>`。
  3. 语言同步升级为**双源**：`detectLang` 优先读 `chrome.storage.local['lingoflow_settings'].uiLanguage`（popup 真源）→ fallback `localStorage['lingoflow_ui_lang']` → 浏览器语言。
  4. 切换时除写 localStorage，还发 `chrome.runtime.sendMessage({action:'update_settings', settings:{uiLanguage:lang}})`，background 用 `getDefaultSettings` 合并写回 storage，popup 下次打开读到一致。
- 经验（可复用）：**Chrome 扩展页面的业务 JS 一律用外链脚本，禁止 inline `<script>`**，否则被 MV3 CSP 直接拦截、整页 JS 静默失效（按钮点不动、报 CSP 错误）。setup-guide.html 因为本来就外链 setup-guide.js 所以没踩此坑。
- 此前 commit c0da4c6 的 z-index/pointer-events 修复是 CSS 层面的，未触根因（JS 根本没执行），本轮才根治。
