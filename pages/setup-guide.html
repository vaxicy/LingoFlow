🔌 接入教程

获取各翻译引擎的 API Key，粘贴到 LingoFlow 设置中即可使用

阿里百炼 AI 有免费额度
阿里云百炼（通义千问）提供 OpenAI 兼容接口，有免费额度，速度快。
  1. 1 访问阿里云百炼控制台，使用阿里云账号登录
  2. 2 进入「API-KEY 管理」，点击「创建新的 API-KEY」
  3. 3 复制以 sk- 开头的 API Key
  4. 4 在 LingoFlow 设置中选择「阿里百炼」，粘贴密钥、选择模型，如用专属工作空间请在 Host 填写控制台地址
前往 阿里百炼 获取 API Key
硅基流动 AI 有免费模型
AI 翻译，支持多种开源模型，免费模型无需付费。
  1. 1 访问硅基流动官网，注册并登录账号
  2. 2 进入「API 密钥管理」页面，点击「新建密钥」
  3. 3 复制以 sk- 开头的 API Key
  4. 4 在 LingoFlow 设置中选择「硅基流动 AI」，粘贴密钥并选择模型
前往 硅基流动 获取 API Key
NVIDIA NIM Free Endpoint
英伟达 NIM 提供 57+ 个免费推理端点，含翻译模型 riva-translate，支持 OpenAI 兼容接口。
  1. 1 访问 build.nvidia.com，注册或登录 NVIDIA 账号（支持 Google / GitHub 登录）
  2. 2 在 Models 页筛选 Free Endpoint，搜索 riva-translate 或其它模型
  3. 3 进入模型详情页，获取 API Key（或使用页面内嵌的测试界面）
  4. 4 复制 Base URL（通常为 https://integrate.api.nvidia.com/v1）和 API Key
  5. 5 回到 LingoFlow 设置，选择「自定义 (OpenAI 兼容)」，填写 Host / Key / Model 名称
前往 NVIDIA NIM 获取免费端点
自定义接口 通用
任何提供 OpenAI /v1/chat/completions 兼容接口的服务均可接入，包括智谱 AI、Ollama 本地部署、OpenRouter 等。
  1. 1 确认你的 API 服务商提供 OpenAI 兼容的 chat completions 接口
  2. 2 从服务商处获取 Base URL（如 https://open.bigmodel.cn/api/paas/v4）和 API Key
  3. 3 确认要使用的模型名称（如 glm-4-flash）
  4. 4 在 LingoFlow 设置中选择「自定义 (OpenAI 兼容)」，分别填入 Host / API Key / Model
Gemini AI 有免费额度
Google AI Studio 提供 Gemini API，有免费额度，速度快。
  1. 1 访问 Google AI Studio，使用 Google 账号登录
  2. 2 点击「Get API key」→「Create API key」
  3. 3 复制 API Key
  4. 4 在 LingoFlow 设置中选择「Gemini AI」，粘贴密钥并选择模型
前往 Google AI Studio 获取 API Key
DeepSeek AI 按量付费 · 低价
高质量 AI 翻译，价格低廉，推荐使用 DeepSeek V4 Flash。
  1. 1 访问 DeepSeek 开放平台，注册并登录
  2. 2 进入「API Keys」页面，点击「Create new API key」
  3. 3 复制以 sk- 开头的 API Key（注意：只显示一次）
  4. 4 在 LingoFlow 设置中选择「DeepSeek AI」，粘贴密钥并选择模型
前往 DeepSeek 开放平台获取 API Key
Microsoft Translator Azure 付费
Azure AI 服务，翻译质量稳定专业，需绑定 Azure 账号。
  1. 1 访问 Azure 门户，登录或注册 Azure 账号
  2. 2 创建「Translator」资源，获取密钥（Key）和区域（Region）
  3. 3 复制密钥（两个 Key 任意一个均可）
  4. 4 在 LingoFlow 设置中选择「Microsoft Translator」，粘贴密钥
前往 Azure 门户获取密钥
有道翻译 需申请
网易有道智云翻译 API，国内速度快，需实名申请。
  1. 1 访问有道智云 AI 开放平台，注册并实名认证
  2. 2 进入「应用管理」，创建应用，获取 App Key 和 App Secret
  3. 3 复制 App Key（应用 ID）和 App Secret（应用密钥）
  4. 4 在 LingoFlow 设置中选择「有道翻译」，分别粘贴 App Key 和 App Secret
前往有道智云获取 App Key
有道大模型 AI 翻译
有道智云大模型翻译 API，基于 AI，翻译质量更高。
  1. 1 同样在有道智云申请，进入「大模型翻译」服务
  2. 2 获取 App Key、App Secret，并选择大模型型号
  3. 3 在 LingoFlow 设置中选择「有道大模型」，粘贴密钥并选择模型
前往有道智云
百度翻译 需申请
百度翻译开放平台，国内稳定，免费额度足够个人使用。
  1. 1 访问百度翻译开放平台，登录百度账号
  2. 2 注册开发者，创建通用翻译应用，获取 APP ID 和密钥
  3. 3 复制 APP ID（应用 ID）和密钥（Secret Key）
  4. 4 在 LingoFlow 设置中选择「百度翻译」，分别粘贴 APP ID 和密钥
前往百度翻译开放平台
百度大模型 AI 翻译
百度翻译开放平台的大模型文本翻译 API，高质量 AI 翻译。
  1. 1 访问百度翻译开放平台，进入「大模型文本翻译」
  2. 2 在「API Key 管理」中创建 API Key（格式为 bce-v3/ALTAK-...）
  3. 3 复制 API Key，粘贴到 LingoFlow 设置中
前往百度大模型翻译
💡 提示：MyMemory 和 Google Translate 无需 API Key，直接在设置中选择即可使用，跳过上述步骤。
