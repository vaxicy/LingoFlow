Privacy Policy LingoFlow

Last updated: July 2025   |   Effective date: July 8, 2026

1. Overview

LingoFlow is a browser extension that helps you read foreign-language websites. This Privacy Policy explains how (and how little) we handle your data.

2. Data We Collect

We do not collect any personal data.

  • No user accounts or login required.
  • No tracking scripts, analytics, or cookies.
  • No data sent to our servers at any time.
  • No third-party advertising or analytics services.

3. Local Storage

All data stays in your browser's local storage (chrome.storage.local):

  • Settings — your translation engine preference, theme, language choice, and API keys.
  • Vocabulary — words and sentences you manually save for learning.
  • History — recent translation records (only if you enable this feature).

This data never leaves your device. You can delete it at any time by clearing the extension data from Chrome's extension management page.

4. API Keys

LingoFlow supports optional integration with third-party translation APIs. When you provide an API key:

  • The key is stored only in your browser's local storage.
  • We never see, collect, or transmit your API keys to any server we operate.
  • The key is sent directly from your browser to the chosen translation service provider when you request a translation.
  • You are responsible for keeping your own API keys secure.

5. Third-Party Translation Services

When you use translation features with an external engine enabled, the selected text is sent directly to the corresponding translation service provider's API endpoint for processing. The specific service depends on which engine you have configured. Please review each service provider's own privacy policy for details on how they handle translation requests.

6. Children's Privacy

LingoFlow does not knowingly collect personal information from children under 13 years of age.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date.

8. Contact

If you have questions about this Privacy Policy, please open an issue on our GitHub repository or contact us through the support channel provided in the extension settings.

This policy was written in compliance with the Chrome Web Store Developer Program Policies regarding User Data Disclosure.
