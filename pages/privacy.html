LingoFlow Privacy Policy · 隐私政策

Last updated: September 11, 2026   |   Effective date: July 8, 2026

1. Overview

LingoFlow is a browser extension that helps you read foreign-language websites. This Privacy Policy explains how (and how little) we handle your data.

2. Data We Collect

We do not collect any personal data.

  • No user accounts or login required.
  • No tracking scripts, analytics, or cookies.
  • No data sent to our servers at any time.
  • No third-party advertising or analytics services.

3. Local Storage

All data stays in your browser's local storage (chrome.storage.local):

  • Settings — your translation engine preference, theme, language choice, and API keys.
  • Vocabulary — words and sentences you manually save for learning.
  • History — recent translation records (only if you enable this feature).
  • Dictionary cache — recent word lookups cached locally to make repeat queries instant (expires automatically).

This data never leaves your device. You can delete it at any time by clearing the extension data from Chrome's extension management page.

4. API Keys

LingoFlow supports optional integration with third-party translation APIs. When you provide an API key:

  • The key is stored only in your browser's local storage.
  • We never see, collect, or transmit your API keys to any server we operate.
  • The key is sent directly from your browser to the chosen translation service provider when you request a translation.
  • You are responsible for keeping your own API keys secure.

5. Third-Party Services

When you use translation features with an external engine enabled, the selected text is sent directly to the corresponding translation service provider's API endpoint for processing. The specific service depends on which engine you have configured. Please review each service provider's own privacy policy for details on how they handle translation requests.

Offline Dictionary (no data transmitted)

LingoFlow bundles an offline English–Chinese dictionary (derived from ECDICT, MIT licensed) inside the extension. Single-word lookups are resolved locally on your device — no network request is made and no data leaves your browser.

Online Dictionary Fallback

If a word is not found in the offline dictionary, LingoFlow may send only that word to one of the following online sources, depending on your settings:

  • Your configured AI or translation engine (requires your own API key).
  • Microsoft Azure Dictionary service (only if you have configured a Microsoft key).
  • The free public dictionary service api.dictionaryapi.dev — no account and no API key are required or sent.

Only the queried word is transmitted. LingoFlow never sends page content, browsing history, or any identifiers along with these requests.

6. Children's Privacy

LingoFlow does not knowingly collect personal information from children under 13 years of age.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date.

8. Contact

If you have questions about this Privacy Policy, please open an issue on our GitHub repository or contact us through the support channel provided in the extension settings.

1. 概述

LingoFlow 是一款帮助你阅读外文网站的浏览器扩展。本隐私政策说明我们如何处理（以及处理得有多少）你的数据。

2. 我们收集的数据

我们不收集任何个人数据。

  • 无需注册账号或登录。
  • 没有追踪脚本、统计分析或 Cookie。
  • 任何数据都不会发送到我们的服务器。
  • 没有第三方广告或统计服务。

3. 本地存储

所有数据都保存在你浏览器的本地存储中（chrome.storage.local）：

  • 设置 — 翻译引擎选择、主题、界面语言以及 API 密钥。
  • 生词本 — 你手动保存的单词和句子。
  • 历史记录 — 最近的翻译记录（仅在你开启该功能时）。
  • 词典缓存 — 最近查询过的单词缓存在本地，用于加快重复查询（会自动过期）。

这些数据永远不会离开你的设备。你可以随时在 Chrome 的扩展管理页面清除扩展数据来删除它们。

4. API 密钥

LingoFlow 支持可选地接入第三方翻译 API。当你填写 API 密钥时：

  • 密钥仅保存在你浏览器的本地存储中。
  • 我们不会查看、收集你的密钥，也不会将其传输到我们运营的任何服务器。
  • 只有你在发起翻译请求时，密钥才会从你的浏览器直接发送给你所选择的翻译服务提供商。
  • 你有责任妥善保管自己的 API 密钥。

5. 第三方服务

当你在使用翻译功能并启用了外部引擎时，所选文本会直接发送到对应翻译服务提供商的 API 接口进行处理。具体发送给哪家服务取决于你配置的引擎。请查阅各服务提供商自己的隐私政策，了解他们如何处理翻译请求。

离线词典（不传输任何数据）

LingoFlow 在扩展内打包了一份离线英汉词典（基于 ECDICT，MIT 协议）。查询单个单词时会在你的设备本地完成解析——不发起网络请求，也没有任何数据离开你的浏览器。

在线词典兜底

如果离线词典中没有收录该单词，根据你的设置，LingoFlow 可能会仅将该单词发送到以下在线来源之一：

  • 你配置的 AI 或翻译引擎（需要你自己的 API 密钥）。
  • Microsoft Azure 词典服务（仅在你配置了 Microsoft 密钥时）。
  • 免费的公共词典服务 api.dictionaryapi.dev —— 无需账号，也不需要发送任何密钥。

仅发送被查询的单词本身。LingoFlow 不会随这些请求附带页面内容、浏览历史或任何标识符。

6. 儿童隐私

LingoFlow 不会有意收集 13 岁以下儿童的个人信息。

7. 政策变更

我们可能会不时更新本隐私政策。任何修改都会发布在本页面并更新修订日期。

8. 联系我们

如果你对本隐私政策有疑问，请在我们的 GitHub 仓库提交 issue，或通过扩展设置中提供的支持渠道与我们联系。
